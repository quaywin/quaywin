### 🔮 About Me

Hi! I'm **Thang Nguyen**, a Software Developer at **@nextid** & **@Impetus-Bet**. I specialize in building distributed, high-performance systems and interactive user experiences. I'm passionate about terminal applications, network orchestration, and backend architecture.

- ⚙️ **Currently focusing on**: Elixir/OTP, TypeScript, Go, and Rust.
- 🛠️ **Building**: Zero-config multi-server log streaming and multi-tunnel VPN orchestrators.
- 🚀 **Specialties**: Network routing, scrapers, Model Context Protocol (MCP) integrations, and developer tooling.
